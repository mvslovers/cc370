CC/370 (cc370) for MVS 3.8j

The host-native cross-toolchain for MVS 3.8j: the C compiler, the assembler, the linkage editor, the archiver and five utilities, all running on a workstation. Two books describe it: the guide shows how to build and run programs, the reference describes every command.
