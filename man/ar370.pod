=head1 NAME

ar370 - OS/360 object-deck archiver with an ESD symbol index

=head1 SYNOPSIS

B<ar370> [B<->]B<rc> I<archive.a> I<obj>...

B<ar370> [B<->]B<t> I<archive.a>

B<ar370> B<--version> | B<-V>

B<ar370> B<--help> | B<-h>

=head1 DESCRIPTION

B<ar370> bundles OS/360 object decks into a B<.a> archive that L<ld370(1)>
auto-calls against. The container is a standard C<ar> archive (host-inspectable),
with a GNU C</>-member symbol table built from each deck's external symbol
dictionary (ESD) so the linker can resolve references without scanning every
member.

=head1 OPERATIONS

The operation is matched whole: B<r>, B<c>, B<rc> or B<cr> create, B<t> lists,
each optionally after a B<->. Anything else is an error.

=over 4

=item B<rc> I<archive.a> I<obj>...

Create I<archive.a> from the given object decks, building the symbol table.
An existing I<archive.a> is B<replaced>, not added to: the archive holds exactly
the decks named on this command. Objects and symbols have no fixed limit.

Each input must be an OS/360 object deck -- 80-byte card images, each beginning
X'02', with an END card. Any other file, an archive included, is refused and no
archive is written.

A member is named after its file's base name. A name of up to 15 characters is
stored in the member header; a longer one, up to 63 characters, goes into a GNU
C<//> long-name member, which L<ld370(1)> and L<file370(1)> read. A name longer
than 63 characters is refused: L<ld370(1)> could not name it with B<--include>.

=item B<t> I<archive.a>

List the archive's members with their sizes, then every symbol of the symbol
table with the member that defines it. A symbol defined by several members
appears once per member.

=back

=head1 OPTIONS

=over 4

=item B<--version>, B<-V>

Print the toolchain version and commit, and exit. Recognised as the first
argument, whatever follows it.

=item B<--help>, B<-h>

Print the usage and exit.

=back

=head1 EXIT STATUS

=over 4

=item B<0>

Success.

=item B<1>

A file could not be read or written, an input is not an object deck, a member
name is longer than 63 characters, or the file given to B<t> is not an archive.

=item B<2>

A usage error: too few operands or an unknown operation.

=back
